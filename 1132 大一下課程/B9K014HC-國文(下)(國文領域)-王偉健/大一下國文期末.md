蘇軾被貶黃州時，常去靈隱寺與佛印禪師喝茶。有次他吟詩說「八風吹不動」，禪師卻幽默回「放屁就動」。蘇軾聽後大笑，從此成趣談。
## 請就個人認知，列出詩詞賞析的方法（10%）
- **識字**：先瞭解字詞本身的基本意義與典故。
- **知人**：結合作者生平與寫作背景，體會其創作動機與心境。
- **論世**：將作品置於當時的時代脈絡或政治、社會背景中解讀。
- **詩法**：觀察格律、平仄、對仗、押韻、修辭等技法，欣賞形式美。
- **意逆**：透過自身感受或想像，體會詩人未明說的深層意境。
- **比較**：將同題材或不同時代、流派的作品相互對照，分析特色與異同。
- **吟唱**：藉由吟誦或配樂，感受韻律節奏，增強作品的聲韻美與情感氛圍。

```
```
《漁家傲》[選]
塞下秋來風景異，衡陽雁去無留意，四面邊聲連角起；千嶂裡，長煙落日孤城閉。
濁酒一杯家萬里，燕然未勒歸無計，羌管悠悠霜滿地；人不寐，將軍白髮征夫淚。
```
《虞美人》借「春花秋月何時了？往事知多少？」一句，先以春花秋月喚起懷舊之情，接著「小樓昨夜又東風，故國不堪回首月明中」將離愁寄託在東風與明月之下，詞人並未直言國破，而是透過「雕欄玉砌應猶在，只是朱顏改」的含蓄比喻，暗示昔日榮景皆已成空，最後「恰似一江春水向東流」將無盡愁緒化作滔滔流水，情感纏綿而內斂，正是婉約詞以細緻意象和隱晦抒情見長的特色。

相比之下，《漁家傲》從「塞下秋來風景異，衡陽雁去無留意」入手，立刻呈現邊塞蒼涼；「四面邊聲連角起，千嶂裡，長煙落日孤城閉」用聲與景營造戰地氣氛，語調宏闊。「濁酒一杯家萬里，燕然未勒歸無計」直抒將士戍邊的豪情與思鄉無奈，「羌管悠悠霜滿地，人不寐，將軍白髮征夫淚」更將悲壯與豪放交織，氣勢磅礴而直率，顯示豪放詞以開闊意境和激昂情懷為旨趣。
## 默寫出「雨霖鈴」（10%），並就個人經寫出300字左右小品文，寫出離別的情緒（20%）（Total : 30%）。
```
《雨霖鈴》[必]
寒蟬淒切，對長亭晚，驟雨初歇。
都門帳飲無緒，方留戀處，蘭舟催發。
執手相看淚眼，竟無語凝咽。
念去去、千里煙波，暮靄沈沈楚天闊。
多情自古傷離別。
更那堪、冷落清秋節！
今宵酒醒何處，楊柳岸、曉風殘月。
此去經年，應是良辰好景虛設。
便縱有千種風情，更與何人說。
```

離別總是在不經意間悄然來臨。記憶裡，我和朋友在校園裡並肩走過的日子彷彿歷歷在目，青蔥歲月中，笑聲與淚水交織，彼此的夢想曾在夏季操場上訴說；如今，當畢業的鐘聲響起，我們只能含著依依不捨的心，揮手道別。那一刻，風輕輕拂過臉頰，捎來淡淡的花香，也吹散了我們曾經的無憂與稚氣。

分別後的日子，總有些寂寞在夜裡襲來，翻看相片，想起昔日同窗，一張張笑臉彷彿在訴說：「未來的路，自當勇敢走下去。」雖然前路茫茫，我們卻要學會將離別的傷感化作前行的力量。雨後的天空彩虹初現，就像我們對明天的期盼，渴望在不同的城市、不同的崗位上繼續追逐夢想。

歲月匆匆，回首所見，是成長的足跡，也是友情的印記。面對未知，我們既感到惆悵，也懷抱希望。離別，並非終點，而是一個新篇章的開始。願我們在人生的旅途中，不負當年深情，一路向前，守住那份純真的信念；即使分隔千里，也能在思念與祝福中相互守望，期待未來某日再次相聚。

## 默寫出「念奴嬌」（10%），並藉由水調歌頭、定風坡，寫出蘇東坡詞風的改變及對人生態度的轉變（20%）（Total : 30%）
蘇軾在《念奴嬌·赤壁懷古》中，憑藉“大江東去，浪淘盡”一句，將赤壁古戰場的壯闊景象與歷史興衰緊密結合，既仰慕周郎當年雄姿，也暗含對自身命運飄搖的哀傷。他提筆時雖仍帶豪放之氣，但更多是懷古傷今：在“故壘西邊，人道是、三國周郎赤壁”與“人生如夢，一樽還酹江月”之間，蘇軾將失國之痛與個人憂思緊緊扣在了一起。及至《水調歌頭》，他以中秋明月為紐帶，從懷古轉向對人事無常的哲理思考——“人有悲歡離合，月有陰晴圓缺，此事古難全”雖道出了他的豁達，卻依然帶有對親情的牽掛，“但願人長久，千里共嬋娟”一句更顯出他雖知世事難全，卻仍心懷希望。到《定風坡》，蘇軾乘著被謫遷後的磨難與漂泊，面對旅途中的風雨，已不再追憶往事或感懷家國，而是以“竹杖芒鞋輕勝馬，誰怕？一蓑煙雨任平生”之語，表現出他最終的超然與自在。這一路走來，他的詞風從懷古中的豪放憂傷，轉為哲理式的抒懷，最終化為面對世事風雨皆能坦然自若的逍遙境界，可見其對人生態度的漸次昇華。

```
《念奴嬌》[必]

在準備這份報告的過程中，我逐漸體會到《岸，你沉沉的睡著了》所揭示的不僅是個人與母親的生離死別，更延伸到整個世代間因歷史洪流而被迫分離的集體記憶。當我研讀詩中那句「我離了岸，母親，我離了岸」，便深刻感受到詩人將「岸」化身為一種懷抱──不只是故土，更代表一種無從回歸的歸屬。報告中對蘇紹連生平與創作背景的整理，也讓我明白他選擇以超現實筆法來呈現悲劇本質，是為了突破具象界限，引領讀者進入更廣闊的想像空間，憑藉詩意的浪潮思辨人生與歷史的多重面向。

在書寫心得時，我特別留意到──詩人將個人與同輩的遙遠漂流與「中國的岸」相對照，既呈現族群文化的割裂，也凸顯了情感聯繫的亙古不滅。原本以為「漂流」只是悲劇的象徵，可是當我撰寫到「漂流未必是悲哀，航向另一個處女地，可能是一種契機」的評析時，才意識到報告中對於詩歌結尾的點評，實際喚起了我對未來可能性的嚮往──即使離鄉背井，也能重新在廣袤的世界尋找意義與新生。

整體而言，這次期中報告最讓我受益之處，除了鞏固我對超現實主義散文詩手法的理解，更在於學會以歷史與情感的雙重視角欣賞台灣文學作品。藉由蒐集作者資料、整理詩歌意象與撰寫品賞文字，我不僅鍛鍊了條理分明的論述能力，也體會到文字與情感交織時的力量。回顧這段過程，我深深感受到，一首詩於報告中不只是文字的堆疊，而是將我整個人的思緒拉進那片詩意的海域，讓我在反覆咀嚼中，重新審視我們所身處的時代與土地，以及語言如何成為承載記憶與連結彼此的橋樑。
