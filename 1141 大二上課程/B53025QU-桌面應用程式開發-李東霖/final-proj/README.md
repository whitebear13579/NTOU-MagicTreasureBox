# ShareLock - 一個安全、高效的檔案分享軟體。
原專案是基於 Nextjs + Firebase SDK 打造的 Web App。
ShareLock 桌面版則是基於現有 API Route 與 Firebase SDK，搭配 AntdUI 與 .NET 8.0 編寫而成的 Windows App。

此應用程式提供使用者非常安全、快速且易用的檔案共享系統。
簡易說明文件如下，如需更詳細的介紹請至web app首頁右上角之 "PDF 下載" 來下載介紹 PDF。
web app 部屬網址: https://www.sharelock.qzz.io

請直接執行 ../RELEASE/sharelock-desktop.exe 方可啟動程式。

(你可以直接試著執行看看，或者直接不要使用第三方登入)

## 系統需求

- 作業系統：Windows 10 或以上版本
- .NET 8.0 Desktop Runtime
- 穩定的網際網路連線（用於連線 Firebase 與上傳/下載檔案）

## 基本使用流程

1. 啟動程式後，首先會看到登入畫面。
2. 使用註冊好的帳號登入，或使用支援的第三方登入方式（例如 Google）。
3. 登入成功後會進入主畫面，可看到自己已上傳的檔案列表。
4. 透過「上傳檔案」按鈕選擇本機檔案並上傳至雲端。
5. 在檔案列表中可對每個檔案進行：下載、查看詳細資訊、產生分享連結或刪除等操作。
6. 若需要登出帳號，可從主畫面左下角點選登出按鈕。

## 主要功能簡介

- 帳號登入與登出：透過 Firebase Authentication 進行身份驗證。
- 檔案上傳：將本機檔案安全地上傳到 Firebase Storage。
- 檔案列表：顯示使用者已上傳的檔案與相關資訊。
- 檔案下載：將雲端檔案下載回本機。
- 檔案分享：產生可分享的下載連結（具權限與安全性考量，亦有身分驗證功能，包含裝置綁定、帳號綁定、PIN碼鎖定與公開）。
- 檔案刪除：從雲端移除不需要的檔案。
